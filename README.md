# entropy-sparse-DCA

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24204103.svg)](https://doi.org/10.5281/zenodo.24204103)

Repository for the manuscript [Expanding functional protein sequence space using high entropy generative models](https://arxiv.org/abs/2605.03578).
Authors: Roberto Netti, Emily Hinds, Francesco Calvanese, Rama Ranganathan, Martin Weigt, and Francesco Zamponi.
It contains the trained models, datasets, and analysis code used to reproduce and inspect the results.

## Contents

- `data_analysis/` — reproducibility package: one script per analysis, the input
  archives, and every figure of the paper. See
  [data_analysis/README.md](data_analysis/README.md) for the figure-by-figure map and
  the instructions to regenerate them.
- `models/tested_models/` — the four models compared in the paper: `eaDCA` (edge
  activation, lowest entropy), `bmDCA` (fully connected), `edDCA` (edge-decimated) and
  `meDCA` (maximum entropy, selected at 12.5 % parameter density).
- `data/` — the natural Chorismate Mutase alignment, the sequences generated by each
  model, and the in vivo relative-enrichment measurements of the tested designs.

Large files are stored with [git-lfs](https://git-lfs.com); clone with `git lfs install`
already done, or run `git lfs pull` afterwards.
